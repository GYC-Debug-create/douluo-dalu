觉醒结果影响

  • 先天魂力换算初始等级：每 10 点 = 1 级，钳制 Lv.1～10
  • 决定初始四维 + 魂技列表
  • 武魂特质 = 事件奖励「武魂共鸣」倍率（如治愈系回血×1.5）
  • 解锁武魂专属事件线与结局（龙系→龙魂传承者等）

界面模式

  • 默认简单模式：顶栏仅 背包/地图/旅行/签到 等，战斗默认自动
  • 可随时切完整模式：开放 商店/任务/技能树/魂骨/锻造/修炼/挑战塔/阵法/成就/称号/关系/图鉴
  • 选择随存档保存，切换不动数据

③ 核心主循环：点「探索四周」（时间 +1）

每次行动按以下优先级从上到下判定（useEventEngine.js · 手册 §3.1），命中即停。

1
主线强制：有等级已达、前置满足的主线里程碑，且人在指定地点？
直接触发主线事件（★ 不进随机池，战败冷却 2 行动后可再试）
2
猎环门槛：Lv 到 10/20/…/90 但缺第 N 环？（缺环时等级封顶 N×10，经验暂存）
进入魂环猎取流程（见⑤成长闭环）
3
连锁待续：上一事件挂了链条？25%
立即触发下一环（共 4 组连锁事件）
4
动态事件：处于特殊状态（濒死/连胜…）？35%
插入动态事件（命运骰子等 5 个）
5
随机池加权抽取：阶段匹配 + 地点匹配 + 等级达标 + 一次性已用过滤，按常见度权重
进入事件（常规 366 + 武魂专属 168）
6
空池休整：以上全部未命中
恢复生命魂力，经验 +25

事件单元结构

  • 出现条件：地点 / 阶段 / 等级≥ / 出身限定 / 时段（仅白天·夜晚）/ 一次性 / 人物
  • 正文若干段 → 选项（可带门槛：攻击≥14、金币≥30、命运值≥5…）
  • 效果结算：经验 / 金币 / 永久四维 / 恢复·受伤 / 命运值 / 物品 / ⚔进战斗 / 跳转其他事件
  • 结算后按武魂特质放大（武魂共鸣）→ 点「继续前行」回到循环

时间 × 天气（后台循环）

  • 时段：清晨(经验×1.2) → 白昼 → 黄昏(遇敌↑) → 夜晚(经验×1.5)
  • 天气：晴 / 多云 / 小雨 / 暴雨 / 迷雾 / 降雪，限制部分事件抽取

④ 战斗子流程（回合制，默认自动）

入口：事件⚔指定 / 旅行遭遇 / 猎环 / 主线 Boss / 挑战塔。名字带「王皇帝」或最终决战不可逃跑。

A
先手：速度高者先动（同速玩家先手）
指令：攻击 / 魂技（耗魂力+冷却）/ 防御【完整】/ 道具【完整】/ 武魂融合【完整：≥3环·40魂力·每场1次】/ 逃跑
B
伤害公式：攻×(0.88~1.12) − 防×0.48（最低 1）
修正链：连击 → 元素克制(克×1.35 / 被克×0.8) → 暴击(率=5%+速度差×0.2%+连击×0.5%，≤65%，伤150%) → 状态增减
C
状态效果：燃烧中毒(掉血) 冻结眩晕(无法行动) 虚弱×0.75 破甲受×1.2 再生(回血) 狂暴×1.3 护盾疾风
自动模式 AI：优先放第一个可用魂技，否则普攻；玩家点任意指令即接管手动；1×/2×/3× 节奏
D
胜利
经验 + 金币；魂兽按年限掉率掉魂骨（Boss 更高品质），加成自动生效
E
失败：不丢档，生命保留 1 点
主线战败给该里程碑 2 次行动冷却后可重试；猎环失败改为反噬扣血（≈最大生命 20%+风险/200）

敌人库：30 种魂兽 × 5 年限档（十年白 / 百年黄 / 千年紫 / 万年黑 / 十万年红），年限档按玩家等级段匹配； 人形对手按玩家面板百分比折算（85%~115%，教皇比比东 血 230%）。

⑤ 成长闭环：升级 ↔ 九次魂环猎取

升下一级所需经验 = round(40 × Lv^1.15)。硬门槛：没有第 N 环时等级停在 N×10，多余经验暂存。

猎环流程（每 10 级一次，共 9 次）

  • 到级触发 → 选猎物（= 年限路线抉择：稳妥 / 成长 / 越级，风险收益不同）
  • ⚔ 战斗 → 胜利吸收魂环并解锁新魂技；失败受反噬，稍后再来
  • Lv.50 第二万年环 → Lv.60 天赐魂环特殊事件（直接吸收 vs 淬炼武魂二选一）
  • Lv.70 十万年红环抉择需 命运值≥5；Lv.90 百万年金环 vs 神赐魂环终极抉择（金环需命运值≥10）
