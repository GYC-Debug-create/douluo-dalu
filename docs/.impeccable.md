# Design Context — 斗罗大陆 · 武魂觉醒（文字 RPG）

## Target audience
中文玄幻/RPG 玩家、斗罗大陆粉丝。桌面端为主、移动端为辅。玩家长时间阅读叙事文本，沉浸感 > 效率。

## Use cases
阅读剧情 → 做选择 → 回合制战斗 → 角色养成（魂环/魂技/魂骨/称号）→ 图鉴/地图浏览。

## Brand personality / tone
**「墨金书卷」—— 暗夜烛光下的一部可玩玄幻小说。**
- 东方玄幻、古籍书卷气、金墨丹青、篆刻印章
- 克制而华贵：深墨底 + 三级金（暗金/正金/亮金）+ 印章红点缀
- 不是霓虹赛博、不是西式奇幻，是中国古典装帧美学

## Design tokens（既有，沿用并强化）
- 底：深墨褐 `#1f1810` 系（多层径向渐变营造烛光氛围）
- 金：暗金 `#8a7a45` → 正金 `#c9a84c` → 亮金 `#e6c878`
- 印：朱砂红 `#b3402a`（仅点缀：印章、地名、副标题）
- 文：米白墨 `#e2d5b3` / 暗墨 `#a89a7c`
- 字：Ma Shan Zheng（标题书法）/ Noto Serif SC（正文宋）/ ZCOOL XiaoWei（点缀）
- 动效：ease-out-expo `cubic-bezier(.16,1,.3,1)`，状态变化为主，拒绝回弹滥用

## Hard constraints
- 不改动任何 JS 引用的 class / id 名称与 DOM 结构，只做纯增强
- 装饰元素只增不删，必须有 reduced-motion 兜底
- 避免纯黑 #000 / 纯白 #fff
