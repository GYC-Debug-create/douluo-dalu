## BUG-DIALOG-001：主游戏剧情内容区过窄，右侧空白过多

- **当前状态**：`ACCEPTED`（2026-08-04）。
- **反馈来源**：截图 `C:/Temp/codex-clipboard-183cb99d-8651-417d-8c03-c10889d365db.png`。
- **现象**：左侧状态栏正常，但标题、正文、图片和选项集中在中央偏左的小区域，宽屏右侧留下大面积空白；玩家实际游玩的剧情区域过小。
- **定位线索**：`frontend/src/pages/GamePage.vue:366` 的主网格；`frontend/src/components/SceneArea.vue:169,177` 的场景布局和 `.scene-event/.scene-continue/.scene-ending` 最大宽度限制。
- **影响/验收方向**：提高宽屏内容利用率，同时保持正文、图片和选项的阅读层级；需要区分容器留白和图片自身构图留白。
- **确认方案**：方案 B——流体铺宽单栏；宽屏剧情容器使用场景内容区约 88%，标题、正文、横幅图片和纵向选项共同铺宽，战斗与空闲场景保持不变。
- **审查结论**：实际差异只涉及 `frontend/src/components/SceneArea.vue` 和 `frontend/browser-smoke.mjs`，另新增本 BUG 的截图证据与实施报告；未修改数据、存档、玩法或其他 BUG。独立复验通过 `npm run build`、前端 `45/45`、根测试 `53/53 + 45/45` 及完整浏览器烟测。真实 Chrome 下 1920/1440 视口剧情区分别占主区域 85.4%/84.3%，五档视口无横向溢出，事件→结果→继续正常，运行时错误为 0。
- **剩余风险**：1199px 与 1200px 媒体查询临界点存在宽度跳变；`.scene-ending` 依赖与事件/结果共用的 CSS 选择器保证一致，尚未通过可达结局流程单独复测。以上均不阻塞本次验收。

- **确认方案**：方案 B——中央问号改为固定 `viewBox` 的内联 SVG；觉醒步骤在宽屏扩展舞台，左右各显示 3 槽黑金武魂图并以 2200ms 错峰轮换，素材不固定为 6 张；觉醒结果出现后停止并淡出，窄屏隐藏，减少动态效果时保持静态且左右不重复。

- **剩余风险**：轮播不相交规则已针对当前 28 张素材池及任意起点验证；若未来素材池缩小到不足 6 张，需要重新定义“左右各 3 张且全部互异”的降级规则。浏览器烟测会重新生成既有截图，因此实施报告所写“R1 原截图原样保留、未覆盖”与文件时间不一致；这不影响当前玩家体验结论，但后续应为每轮证据使用不可覆盖的新路径。

## BUG-DIALOG-003：神级保底计数没有按出生选择/玩家存档隔离

- **当前状态**：`ACCEPTED`（2026-08-05）。
- **反馈来源**：用户在更换出生后仍保留以前的神级保底数量。
- **现象**：开始选择新的出生或角色流程后，神级保底计数继续沿用此前流程的数量。
- **定位结论**：旧实现使用浏览器全局单值键 `dldl_god_spirit_pity`，没有当前创建流程和出身维度，导致不同出身及不同新角色流程共享计数。
- **确认方案**：方案 B——保底只属于当前角色创建草稿；使用 `draftId` 和四个出身的独立计数。刷新仅保留保底计数，不恢复姓名、步骤或武魂；标题页“新的旅程”将四个出身全部归零；旧全局键直接删除且不迁移。
- **确认规则**：普通觉醒只增加当前出身并在 50/50 封顶；自然神级和手动自选神级只清零当前出身；其他出身保持不变。确认角色并成功保存后清除创建草稿，正式存档不写入保底字段；保存失败则保留草稿以便重试。
- **审查结论**：实际业务改动限于 `frontend/src/pages/CreatePage.vue`、`frontend/src/pages/TitlePage.vue` 和新增的 `frontend/src/utils/creation-pity.js`，并补充对应单测、浏览器烟测、实施报告及截图证据。独立复验通过数据校验、构建、根测试 `53/53`、前端测试 `87/87` 和完整浏览器烟测。真实 Chrome 验证了星斗 17/50 与武魂城 1/50 相互隔离、刷新保留、新旅程归零、49→50 解锁、50 封顶、两种神级仅清当前出身、确认后草稿清除且正式存档无保底字段；BUG-001/002 回归及控制台/关键网络错误检查均通过。R2 两张证据图经人工目视确认文字和按钮实际可见；R3 将混合编码报告修复为严格 UTF-8，原 R1/R2 正文逐字符保持一致。
- **剩余风险**：R1 烟测覆盖前的历史截图没有备份，无法恢复；现已用“只写一次”机制阻止后续覆盖，并独立验证完整烟测前后 20 张截图的 SHA256、修改时间和长度均不变化。项目目录整体未纳入 Git 跟踪，无法提供可信的逐行历史 diff，本次以文件范围、源码、时间和哈希交叉审查；浏览器拒绝或无法写入 localStorage 时创建流程不会崩溃，但保底无法跨刷新持久化。

## BUG-DIALOG-005：点击重新觉醒时按钮短暂消失，连续操作产生视觉闪断

- **当前状态**：`ACCEPTED`（2026-08-06）。
- **反馈来源**：用户实际游玩反馈。
- **现象**：点击“重新觉醒”后，中间按钮在武魂刷新完成前消失；如果连续多次点击，画面在按钮消失、武魂刷新、按钮重新出现之间反复变化，造成明显的视觉不适。
- **定位结论**：刷新过程复用了“结果是否已揭示”的状态控制操作控件，导致约一个刷新窗口内按钮被卸载；不是单纯点击过快。
- **验收方向**：刷新期间应保持稳定的操作位和明确的处理中状态，连续点击不应让核心布局跳变。
- **确认方案**：方案 B+——首次觉醒保留原 650ms 仪式；重新觉醒改为真实快速重抽，旧结果在连续点击期间保留并压暗，停止约 250ms 后只展示最新结果。每次有效点击仍执行一次完整抽取和一次保底更新；神级或首次 49→50 立即停止并进入约 650ms 安全锁，顶级不停止，50/50 永不溢出。
- **审查结论**：业务实现限于 `frontend/src/pages/CreatePage.vue`，补充对应 UI 单测与浏览器烟测、实施报告和 8 张截图证据。独立复验通过 `npm run validate:data`、`npm run build`、根测试 `53/53`、前端测试 `125/125` 和完整浏览器烟测。真实 Chrome 使用同一固定坐标连续点击 10 次，按钮焦点与逐次矩形保持稳定，保底 1→11，旧结果不闪断；神级与 49→50 分别在 63ms/16ms 内停止，安全锁尾随点击不消耗随机数；1920/1440/1024/768/390 五档的三按钮和四按钮形态逐按钮误差均不超过 1px；处理中离开重进无陈旧回调，reduced-motion 规则一致，控制台和关键网络错误为 0。
- **剩余风险**：快速收敛 250ms 与安全锁 650ms 是当前产品节奏常量，未来若调整应同步更新测试；390px 操作区会纵向换行并需要页面滚动，但无横向裁切且实际按钮均可到达。项目目录整体未纳入 Git 跟踪，仍以允许范围、源码、文件时间和截图哈希交叉审查。

## BUG-DIALOG-006：地图地点标记 hover 层级过多并持续颤动

- **当前状态**：`ACCEPTED`（2026-08-06）。
- **反馈来源**：截图 `C:/Temp/codex-clipboard-92e415c6-6503-4443-bd49-512c21871fb1.png`。
- **现象**：鼠标移入地点时依次出现淡圆、空心圈、填充圈和地标图标，并伴随持续颤动；多个 DOM 层与动画叠加，玩家难以判断哪个才是地点状态。
- **用户方向**：参考网游地图交互，移入地区时突出地区边界（例如金色描边）并轻微放大，而不是让单个地点标志反复抖动。
- **定位结论**：当前实现缺少区域边界几何，使用的是地点坐标、圆环和图标层；需要重新定义“地点 hover”和“区域 hover”的交互模型。
- **确认方案**：现有数据没有地区边界几何，采用“单一地点影响区”作为诚实降级：固定 60×60 命中盒不缩放，删除常驻脉冲和旋转环，只让一个椭圆影响区在 hover/键盘焦点时做 180ms 淡入；当前地点和相邻地点仅保留不同强度的静态状态，雾区隐藏。地点名称不再形成重复键盘交互点。
- **审查结论**：业务实现限于 `public/map.html`，新增 5 项根测试、BUG-006 浏览器烟测、实施报告和 3 张前后对比截图。最终复验通过 `npm run validate:data`、`npm run build`、根测试 `58/58`、前端测试 `125/125` 和完整浏览器烟测。真实 Chrome 确认地点子层由 6 层收敛为 5 层且全部 `animation-name:none`，hover 根矩形误差不超过 1px，两个地点快速交替 12 次无颤动；1440/1024/768/390 四档与 reduced-motion 均无无限动画、无横向溢出，唯一被忽略的控制台噪声是浏览器自动请求 `/favicon.ico` 的 404。
- **剩余风险**：当前采用地点影响区而非真实行政/地理多边形；若未来补充边界坐标，可把单椭圆升级为 SVG 区域描边，但不得重新引入命中盒缩放或无限脉冲。该限制不阻塞本次验收。

## BUG-DIALOG-007：地图与旅行/地点玩法脱节，快速旅行缺乏实际意义

- **当前状态**：`ACCEPTED`（2026-08-06）。
- **反馈来源**：用户地图游玩反馈。
