# 入口与框架（板块 A）· 玩家视角体验优化

> 复查日期：2026-08-03
>
> 立场：一个不读代码、第一次打开游戏的普通玩家。TA 不会关心"游戏有没有这个功能"，
> 只会在心里回答三个问题：
> 1. **我现在在哪个"世界"里？**
> 2. **我下一步应该点什么、点了以后会发生什么？**
> 3. **我的进度是不是真的、是不是还在？**
>
> 本文件只看板块 A（game.html / index.html / server.js / map.html / codex.html / 双套 CSS）
> 里"玩家体验"的部分。技术/安全项见《入口与框架-A-深度体验审查.md》。

---

## 一、玩家视角下板块 A 的"体验清单"

玩家在板块 A 里实际经历的五个场景：

1. **我打开页面** —— 看到什么、要不要跳过动画、有没有被打到一脸信息。
2. **我开始新游戏** —— 填名、选出身、觉醒，页面是否干净、有没有旧角色残影。
3. **我继续游戏** —— 看到几个存档、哪个是我、读了以后会不会丢。
4. **我在游戏里玩** —— 地图/图鉴/工具按钮什么时候能点、点了去哪，返回时能不能回来。
5. **我换了设备或刷新** —— 进度还认不认得我。

下面按这五个场景给体验问题（不是技术问题）。

---

## 二、体验问题与优化建议

### E-1 两个"同一个名字却不同的游戏"（入口识别）

**玩家体验**：有人在书签或群里给你发了个 `127.0.0.1:3000/index.html` 的链接，打开以后你看到
一本像素游戏，键盘 WASD、紫色 UI，标题写着《斗罗大陆·武魂觉醒》。第二天你又收到
`/game.html`，这次是羊皮纸一样的小说界面，也是《斗罗大陆·武魂觉醒》。你会：
- 以为这是同一款游戏，只是页面不一样；
- 在像素版里输名字想"接着玩上次的文字角色"，结果看到的是另一套存档；
- 分不清哪个是现阶段更新、哪个是旧的"试玩版"。

**体验判断**：身份混乱是本板块最伤信任的地方——**同一个名字不能被两个差异很大的产品共享**。

**优化建议（高收益）**：
1. 在旧 Canvas 版显著标注"旧版像素原型 / 仅体验用"，主菜单里把它从"新手默认入口"移走，
   变成帮助角落里的"历史版本"链接；
2. 两个页面用不同副标题（如"文字RPG·正式" vs"像素试玩"），字体、图标甚至级联颜色给以区分；
3. 建立**官网首页式入口**：`/` 就是明确的产品名，其它版本一律收进"历史"。

### E-2. "开始新游戏"要看到接下来会发生什么（引导缺口）

**玩家体验**：点“新的旅程”，于是直接跳到"写下你的名字"。玩家不知道：
- 接下来要经历几个步骤（名字 → 出身 → 觉醒）？
- 大概要多久才能开始玩？
- 出身会影响什么（会不会选错就把开局毁了）？

从头到尾用户都是"下一步、下一步"，靠猜。

**优化建议**：
- 新游戏按钮下加一行节奏提示："约 2 分钟完成角色创建"，消除"要等很久才好玩"的焦虑；
- 三个步骤进度点（名字 / 出身 / 觉醒）加上说明。出身卡片上写"推荐新手"，避免选错；
- 觉醒完成后明确"这就是你的第一魂环进度 / 第一段主线"，给出 1 个“开始冒险”主按钮过渡、再接开场剧情。

### E-3. 标题页面直接开放"万象图鉴"，让我看到一堆还没玩的内容（信息密度/剧透）

**玩家体验**：在标题页第一屏就有一个"万象图鉴"按钮。我一点，整个世界的魂兽、武魂、人物、
地点全一览无余（这是玩家真正想要的深度内容）。于是：
- 我看到了几十个武魂、几百条特性，但自己才刚觉醒；
- 我的"旅程是探索"被这个开放词条提前剧透、提前无聊；
- 图鉴的"未解锁"概念对新手没有意义，因为我根本分不清哪些是未解锁。

**体验判断**：标题页的图鉴入口不符合"成长即探索"的心智 —— 玩家应该**在和世界互动中才逐渐看到图鉴**。

**优化建议**：
- 标题界面上，把"万象图鉴"从主菜单第一组拿掉，或者入口显示成"图鉴(世界待探索)"，点开后默认只显示"我认识的/相关性高的"分类；
- 游戏前进去的图鉴页，默认折叠"未解锁条目"，只有满足条件（初见·获取·击杀）才展示；
- 用"图鉴进度"要求将入口再造为目标："点亮 10 个地点 / 见过 1 只魂兽"才有图鉴权限。

### E-4. 新旅程开始后还带着旧角色的广告（残影污染）

**玩家体验**：我上。玩过另一个角色，点“重新开始”后，刚觉醒完还在看戏，页面上弹出
"成就解锁：圣者之心"、一直出现"已结识唐三""背包：回魂丹×2"——但我这个新角色根本还没遇见唐三、
没做过成就。会以为："这是不是加载了我之前的账号？我是不是被秒成大号了？"

**体验判断**：这是"新游戏=新的自我"最直接被打破的场景，也是板块 A 最能劝退新玩家的点之一。

**优化建议**：
- 每次"开始新的旅程"先显式清空：成就横幅、NPC 结识提示、Toast 队列、打开中的弹窗；
- "新角色确认"时给一句明确反馈（"你崭新的魂师旅途开始了"），把旧角色的残留全部消灭；
- 成就、人物、背包等数据在"角色"层面隔离，实现"当前角色=当前一切"的三段式语义，而不是默认继承。

### E-5. "继续冒险"的存档谁是我？（存档识别）

**玩家体验**：点"继续冒险"后，跳出一个列表：本地这份、云端那份，还有好几个别的等级的档
（比如 Lv.100、神级魂师——但你只玩到 Lv.4）。每个都带"读取/删除"。我会：
- 分不清哪一份是我真玩出来的最新进度；
- 怕点了云端读取，把本地 90 分钟好不容易打的进度顶掉；
- "本地/服务器/备份恢复"这些词让普通玩家晕。

**体验判断**：继续入口是存续留存最核心的按钮，不该是一个有歧义的列表。

**优化建议**：
1. 排第一的永远是"当前角色·最新本地档"，展示摘要：名字、等级、当前地点、魂环数、最后活动时间；
2. 其他所有档（云端/历史）折叠到"更多记录"需二次确认读取；
3. 删除按钮统一走到"选中的摘要 + 确认弹窗"，规定影响范围（只删这份的本地 / 只删云端 / 一起删）；
4. 文案上把所有"备份恢复"改成玩家语言："上次自动保存"。

### E-6. 地图/图鉴的顶部导航在"独立页"和"游戏内"行为不一样（语义不稳）

**玩家体验**：在游戏里点"地图"，页面左上角是"← 返回游戏"；我退出到标题，再直接输入 map.html，
这时左上角又变成"← 返回主页"。同一个按钮、同样的"返回"，跳的目的地却依附于它从哪里来——
在"我"的语境里，我把地图当作独立页归档，回到的是哪儿？之前和之后，我在逻辑上不一定是一样的地方。

**体验判断**：子页面（地图/图鉴）的"返回键"必须永远提到同一套上下文，玩家才能形成肌肉记忆。

**优化建议**：
- 统一规则：任何页面顶部"返回"都回"游戏内当前所在屏"（有档），无档回"标题"；不依赖入口来源；
- SPA 内嵌和独立打开尽可能共用同一页面模板，只隐藏一层装饰条（iframe 时的顶栏），导航语义不变；
- 独立打开的 map/codex 增加"当前角色"角标，避免玩家看两份不一致的"当前位置"。

### E-7. 首屏信息太多：四组菜单 + 9 个空魂环槽（信息降噪）

**玩家体验**：进入正文世界第一屏，左边有头像、血条、经验、角色称号，右边顶上趴着「常用/成长/人物与图鉴/系统」四组菜单，里面还有 Thần20 个入口；左边魂环区域直接显示 9 个空槽，第一 件全是“达到对应等级后猎取”。
一个新手此刻内心的样本是：“塔的事现在都跟我无关”——但选项把一切摊在我脸上。

**体验判断**：信息架构不是"没有东西"，是"东西没有优先级"，会稀释"我该做什么"。

**优化建议**：
1. 首屏只保留：当前地点、当前目标卡（推荐行动）、HP/魂力/经验、一个魂环（未获取的显示"第一个魂环已就绪"，而不是排 9 个空位）；
2. 其余系统（技能树/锻造/阵法/成就/称号/塔）折叠成一个统一的"更多…"二级菜单，前 3 天不常用的一律隐藏入口；
3. 顶部四组菜单在移动端改成抽屉/底部栏，适配已有 UX-023 的"紧凑状态条"，保留“当前任务”操作。

### E-8. 关键性场景（如开始探索、第一次猎魂）缺少"下一步"按钮

**玩家体验**：主线卡上写着"下一主线：Lv.5「第一次猎杀」"、'魂环 0/9·下一魂环 Lv.10'，但正文里没有"去猎魂森林""去修炼""开始猎环"任何按钮。我除了继续看随机事件，没有任何能动的手柄。帮助页又说"点击探索按钮触发"，但根本没有探索按钮。
这让 Lv.4 玩家在"我明明目标对了，却不知道怎么做"的卡点。

**优化建议**：
- 把"主线里程碑"做成任务卡：显示"当前目标 / 距离 / 推荐地点 / 还需要什么（等级 or 金币 or 魂环）"；
- 卡片上放 2 个真实按钮："前往猎魂之地""修炼提升"，与地图、修炼系统直接连通；
- 若做不做战斗字段，也至少给"测试"提示：官方给 1 个明确"猎环"入口，取代"去随机事件里赶路"。

### E-9. 设备切换的"续命感"（桌面 ↔ 手机）

**玩家体验**：在手机上把状态栏收起后，我进入正文看到剧情，但我不知道自己的等级/血量/魂环，
必须主动展开状态栏。而且我平时玩到一半刷新页面，回到标题，能点击"继续冒险"恢复——很友好；
但拿到不同设备登录一下，就发现云服务器帮助我同步的事被"本地/服务器"标签绊住了。

**优化建议**：
1. 移动端默认显示"紧凑状态条"（等级·HP·魂力·当前目标·金币），一屏始终可见，展开才看全；
2. 首次打开自动提示"进度会自动保存到本机，建议再用账号登录云端"，显式解释双通道；
3. 恢复原启动：进标题前先读最近存档"加载成功"，减少"这是不是新的"的怀疑。

## 三、影响排序（玩家视角）

| 优先级 | 问题 | 因为 |
|---|---|---|
| P0 | E-4 新旅程继承旧角色残留 | "这是不是新游戏"直接破坏信任 |
| P0 | E-5 继续冒险存档识别不清 | 进度是玩家资产，识别错 = 全防线崩塌 |
| P0 | E-8 有目标无按钮 | 玩家被卡在"不知道怎么开始玩"最初 10 分钟 |
| P1 | E-1 双入口同名不同游戏 | 身份与版本混淆 |
| P1 | E-2 创建流程无节奏/无预告 | 从路面降到"看下一步" |
| P1 | E-7 首屏信息噪音重 | 目标被稀释 |
| P2 | E-3 标题页全量图鉴剧透 | 破坏探索与解锁的成长感 |
| P2 | E-6 子页返回语义不统一 | 页面肌肉记忆断裂 |
| P2 | E-9 移动端状态可信 | 服务体验一致 |

## 四、立即可以做 & 慢慢做

**这周就能改（不依赖系统重构）**：
- E4：新旅程清 toasts / 通知 / 弹窗状态（改 create flow 的 reset 一块）；
- E5：存档列表"本地最新"第一位 + 摘要 + 一次确认；
- E8：主线卡下一枚"前往猎魂/去修炼"按钮（同一处入口连通）；
- E1：旧 Canvas 出入口加"旧版像素原型"标签，主题末尾标注。

**中期（跟系统重构一起）**：
- E7：首屏信息收敛（9 空环槽→下一环目标卡；20 入口→折叠菜单）；
- E6：地图/图鉴返回语义统一 + 独立打开授权当前角色角标；
- E3：图鉴逐步解锁（按所见所得解锁），新档默认只显示已见/可解锁；
- E9：压缩渲染 + "备用账号"。可视化状态条。

> 一句话给板块 A 的体验结论：**不是"进不去"，而是"进去了不知道自己在哪、该干嘛、进度算不算数"，** 三件事之间缺一个统一的"当前状态"卡片。把它做成唯一权威：入口请确保它永远处于玩家第一眼能看到的位置。
