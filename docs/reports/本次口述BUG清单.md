每个 BUG 必须依次经过以下步骤：

1. 用户描述 BUG。
2. 我向用户复述对 BUG 的理解；此时不写入本文件。
3. 用户明确确认复述无误。
4. 我将确认后的内容写入本文件，并告知用户已经记录。

如果用户纠正或补充描述，我必须重新复述，并再次等待明确确认。未经确认的内容不得记录。
