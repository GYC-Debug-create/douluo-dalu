## 总体结论

游戏可以完成“创建角色 → 出身选择 → 武魂觉醒 → 跳过序章 → 早年经历 → 学院报到 → 分班 → 第一堂课”的前半段首通。  
但魂环、魂技、等级、战斗和存档之间存在明显的数据没有统一问题，当前不能称为完整游戏。  
最影响体验的三个问题是：**魂环技能名称与战斗技能名称不一致**、**主线显示了目标但没有提供实际入口**、**Toast/成就通知和移动端布局会遮挡或挤出核心操作**。  
当前游戏更像是“功能很多，但规则、数据和网页体验尚未统一的系统集合”，而不是完整闭环的 RPG。  
正式战斗界面确实存在，挑战塔也能进入真实回合战斗；但自然首通没有走到 Lv.10 魂环和完整战斗成长循环，后期内容不能用已有高等级存档替代验证。

### P1-01：魂环技能名称与战斗技能名称不一致

- **严重程度**：P1
- **玩家实际操作路径**：  
  首页可见继续档 → 进入游戏 → 查看第一个魂环 → `成长 → 挑战塔 → 第1层 → 可挑战` → 进入战斗。
- **实际看到的结果**：
  - 主界面魂环卡显示：  
    `1 / 流光斩 / 独眼狼 / 百年魂环`
  - 点击魂环卡后的魂技详情显示：  
    `流光斩`、`百年魂环`、`来源：独眼狼`
  - 进入战斗后，战斗操作按钮却显示：  
    `🔥 烈焰斩　5魂力`
  - 战斗日志继续写：  
    `浏览器魂师释放「烈焰斩」`
- **玩家合理预期**：  
  第一个魂环获得的魂技应该在魂环卡、魂技详情、战斗按钮和战斗日志中始终使用同一个名称。
- **为什么影响体验**：  
  玩家无法确认自己真正获得了什么技能，也无法判断战斗按钮是否使用了魂环技能。魂环是成长系统的核心奖励，这种错名会直接破坏奖励可信度。
- **是否稳定复现**：  
  在当前可见高等级存档中稳定复现。
- **问题性质**：明确 BUG，属于魂环数据与战斗数据没有使用同一套技能定义。
- **建议修复方向**：
  1. 用唯一魂技 ID 作为跨系统数据源。
  2. 魂环卡、魂技详情、战斗按钮、战斗日志全部从同一个 ID 读取名称、图标、元素、消耗和冷却。
  3. 增加自动校验：获得魂环后的技能名必须与战斗技能名一致。

### P1-02：主线目标存在，但玩家不知道如何开始下一步

- **严重程度**：P1
- **玩家实际操作路径**：  
  新的旅程 → 输入名字 → 选择出身 → 觉醒武魂 → 跳过序章 → 完成早年经历并推进到 Lv.4。
- **实际看到的结果**：
  主界面一直显示：

  `下一主线：Lv.5「第一次猎杀」`

  但页面没有看到“探索”“猎杀魂兽”“前往猎魂地点”或“开始任务”按钮。  
  顶部菜单实际只有：

  `背包、商店、地图、旅行、任务、签到、技能树、魂骨、锻造、修炼、挑战塔、阵法、成就、称号……`

  帮助页面却写着：

  `探索：点击「探索」按钮触发事件，事件类型包括战斗、奇遇、商店、休息等。`

- **玩家合理预期**：  
  看到“Lv.5 第一次猎杀”后，应当知道要点击什么、去哪里、是否需要修炼或旅行。
- **为什么影响体验**：  
  主线目标和实际入口脱节。玩家只能继续点击随机剧情或自行打开大量外围菜单，无法确定哪个操作会推进主线。
- **是否稳定复现**：  
  新存档前半段稳定复现。
- **问题性质**：逻辑不通、引导设计缺失，帮助文本同时存在过时说明。
- **建议修复方向**：
  1. 在主线卡上增加明确按钮，例如“前往猎魂森林”。
  2. 当等级不足时显示“还差多少经验、推荐做什么”。
  3. 删除帮助页中不存在的“探索按钮”，或者真正提供探索入口。
  4. 把“主线、等级、魂环条件、地图入口”放在同一个可操作任务卡里。

### P1-03：Toast、成就通知和剧情选项互相遮挡

- **严重程度**：P1
- **玩家实际操作路径**：  
  推进早年经历、完成关键选择、结识 NPC 或解锁成就。
- **实际看到的结果**：
  在 1366×768 页面中，曾同时看到：

  - 底部 Toast：`✦ 结识了「唐三」！人物图鉴已更新`
  - 顶部成就通知：`成就解锁 / 圣者之心`
  - 剧情选项按钮位于页面下方

  实际几何位置中，Toast 位于约 `y=707`，而剧情第二个选项从约 `y=717` 开始，Toast 会压住选项顶部区域。  
  390×844 竖屏时，Toast 还会覆盖场景标题附近内容。
- **玩家合理预期**：  
  通知应该避开正文和选择按钮，或者在显示通知期间暂停选项交互。
- **为什么影响体验**：  
  玩家可能看不到完整选项，也可能误点通知区域。尤其是在带有长期后果的剧情选择中，遮挡核心操作是严重问题。
- **是否稳定复现**：  
  在出现 NPC 通知、成就通知和 Toast 的事件中可以复现。
- **问题性质**：明确 UI BUG。
- **建议修复方向**：
  1. 为通知建立统一的非阻塞区域。
  2. Toast 不得覆盖 `.choices`、剧情正文和固定操作栏。
  3. 多条通知进入队列，不要同时从顶部和底部弹出。
  4. 移动端改为固定在剧情区域之外，或暂时缩短通知并自动避让。

### P1-05：移动端顶部菜单和剧情操作会被挤出屏幕

- **严重程度**：P1
- **玩家实际操作路径**：  
  分别使用 390×844、844×390、768×1024、1366×768、1920×1080 检查页面。
- **实际看到的结果**：
  - 390×844：
    - 页面高度约 1435px。
    - 场景区域从约 `y=761` 才开始。
    - 剧情选项位于约 `y=986` 和 `y=1055`，首屏看不到。
    - 打开顶部菜单后，部分菜单按钮出现负坐标，例如 `x=-110`、`x=-11`。
  - 844×390 横屏：
    - 帮助弹窗内容高度约 615px，超出可视高度。
    - 剧情按钮出现在约 `y=615` 和 `y=684`，需要滚动。
  - 768×1024：
    - 魂环槽、属性和剧情按钮继续向下延伸，核心信息不在首屏。
- **玩家合理预期**：  
  移动端至少应能看到当前状态、剧情正文和当前选项；菜单不能被定位到屏幕外。
- **为什么影响体验**：  
  这不是单纯需要滚动的问题，而是玩家可能看不到下一步、找不到菜单按钮，甚至无法点击菜单项。
- **是否稳定复现**：  
  在上述尺寸下稳定观察到垂直溢出；390px 竖屏打开菜单时负坐标问题可复现。
- **问题性质**：响应式布局 BUG。
- **建议修复方向**：
  1. 移动端改为单列布局，状态栏和剧情区独立滚动。
  2. 顶部菜单改为抽屉或底部菜单，不要继续使用桌面端横向绝对定位。
  3. 核心剧情选项固定在可视区域底部。
  4. 检查所有弹窗的 `max-height`、内部滚动和横屏布局。

  2. 区分当前生命恢复与最大生命增加。
  3. 显示魂力上限变化、当前魂力恢复和命运值变化的具体数值。

### P2-05：技能树、阵法和锻造在正常可达状态下更像说明书

- **严重程度**：P2
- **玩家实际操作路径**：  
  `成长 → 技能树 / 阵法 / 魂骨锻造`。
- **实际看到的结果**：
  - 技能树显示：  
    `可用技能点：0 / 0`，下面列出大量节点和消耗，但当前弹窗中实际可操作控件只有关闭按钮。
  - 阵法显示多个阵法名称和加成，但没有明显的选择、确认或当前状态反馈按钮。
  - 魂骨锻造显示 8 种配方，当前材料为 `0块`，所有“锻造”按钮禁用；只说明材料可以通过挑战塔、精英魂兽、秘境获得，但新存档没有明确最近入口。
- **玩家合理预期**：  
  被锁定的节点应明确显示“Lv.5解锁”“需要2点技能点”；可用系统应有清晰操作和结果反馈。
- **为什么影响体验**：  
  玩家看到很多系统，但无法确认何时可用、如何解锁、操作是否成功。
- **是否稳定复现**：  
  在 Lv.4 的自然早期状态稳定复现。
- **问题性质**：内容缺失、交互设计不足；锻造禁用本身符合材料不足，但缺少可执行引导。
- **建议修复方向**：
  1. 未解锁节点显示具体条件。
  2. 可点击和不可点击状态视觉区分。
  3. 阵法选择提供“当前阵法、选择、确认、属性变化”。
  4. 锻造入口关联到获取材料的实际任务或地图。

### P2-07：战斗数值反馈缺少可解释性

- **严重程度**：P2
- **玩家实际操作路径**：  
  继续档 → 挑战塔第1层 → 进入石像守卫战斗。
- **实际看到的结果**：
  - 玩家攻击显示为 `3`，敌人防御为 `10`。

  - 敌人攻击出现 `22点伤害（暴击）`、`13点伤害`、`11点伤害`。
  - 防御操作显示：

- **为什么影响体验**：

- **建议修复方向**：
  1. 日志显示基础伤害、减伤、克制倍率和最终伤害。
  2. 对“元素克制但只造成1点”给出原因。
  3. 在战斗帮助中说明最低伤害、暴击和防御公式。

### P3-01：地图页面空间利用率低，视觉上像图片查看器

## 最终判断

### 1. 玩家能否知道下一步做什么？

**只能部分知道。**

创建角色、觉醒、跳过序章和点击继续都比较明确。  
但进入成长阶段后，玩家看到的是：

`下一主线：Lv.5「第一次猎杀」`

却不知道应该探索、修炼、旅行、打开任务，还是等待随机事件。帮助页提到的“探索按钮”实际不存在，导致主线目标和实际操作断开。

### 2. 玩家是否相信数值和奖励？

**目前不能完全相信。**

早期剧情中的经验、命运值、攻击和防御大多会变化，部分事件也会明确列出奖励。  
但以下问题会严重破坏信任：

- 魂环技能名称和战斗技能名称不同。
- Lv.50 存档只有1个魂环。
- 统计页、战斗角色卡和魂技描述的元素字段不统一。
- 某些选择会改变属性，但结果正文不显示具体奖励。
- 魂骨稀有度直接显示 `epic / legendary / divine`。

### 3. 玩家是否能感知自己的选择带来了长期变化？

**可以感知到部分数值和记录变化，但很难感知世界变化。**

选择确实会影响：

- 攻击、防御、经验、命运值
- 关键选择计数
- 仁慈、雄心、忠诚等路线统计
- 成就和称号
- 日记内容

但在实际走过的前半段，没有明显看到地图、NPC关系、地点资源或主线分支发生相应变化。人物关系仍然是 `陌路人 0/20`，多数选择更像是“换一段文字并增加一个数值”。

### 4. 地图、NPC、魂环、战斗和主线是否形成闭环？

**没有形成稳定闭环。**

- 地图可以展示当前位置、相邻地点和未探索地点。
- NPC 图鉴可以通过剧情结识人物。
- 挑战塔可以进入真实战斗。
- 魂环卡可以显示技能详情。

但主线没有把玩家明确带到猎魂地点，魂环获取没有在正常首通中完成，战斗技能又与魂环技能名称不一致。地图、NPC、魂环、战斗和主线目前是几个能够分别打开的系统，而不是一条可靠的成长循环。

### 5. 这款游戏现在最需要减少什么、补什么、重做什么？

- **需要减少**：
  - 首屏重复的9个空魂环卡。
  - 大量直接展示的内部数值。
  - 重复 NPC 通知。
  - 同时出现的 Toast、成就和奖励弹窗。
  - 没有实际内容的空入口。

- **需要补上**：
  - 明确的“当前主线 → 下一步按钮 → 地点 → 战斗/魂环 → 奖励 → 日记”链路。
  - Lv.5、Lv.10 等关键门槛的可操作引导。
  - 魂环失败、逃跑、吸收失败和重试状态。
  - 保存、读取、等级、魂环、主线之间的完整校验。
  - NPC关系、地图变化和选择后果的叙事反馈。

- **最需要重做**：
  1. 魂环、魂技、元素和战斗数据的统一模型。
  2. 主线和猎魂成长循环。
  3. 移动端页面结构和通知层。
  4. “功能很多但不可操作”的外围系统。
  5. 存档和继续冒险的进度完整性。## 总体结论

这款游戏可以完成一段可玩的首通前期流程：创建角色、武魂觉醒、早年经历、魂师登记、学院推荐、报到分班和第一堂课都能实际进入。  
但中后期无法被当作可信的完整游戏体验：正常首通在本次实测中只推进到 Lv.4，下一主线显示为 Lv.5「第一次猎杀」，却没有明确的猎杀入口或行动指引。  
最影响体验的三个问题是：完成存档数据自相矛盾、挑战塔进入战斗后弹窗仍然遮挡战斗、移动端核心按钮和选项被推到屏幕外。  
另外，新的旅程会继承旧的成就提示、NPC 通知以及部分界面状态，玩家会怀疑自己是否真的开始了新角色。  
后期我通过游戏自身“存档管理”中已经存在的存档进行验证，没有修改 G、localStorage 或源码；这些结果不应被视为自然首通。  
总体判断：当前更像是“功能很多但体验未统一的系统集合”，还不是一个可以放心交给普通玩家长期游玩的完整游戏。

## 发现的问题

### P0-01：已完成存档的魂环数量、主线状态和当前剧情互相矛盾

- **严重程度：** P0
- **玩家实际操作路径：** 主页 → 继续冒险 → 存档管理 → 读取网页中已有的 Lv.100 存档。
- **实际看到的结果：**
  - 顶部显示：`等级 100 · 神途篇 · 神级魂师`
  - 显示：`主线已完成`
  - 显示：`魂环 97/9`
  - 页面只渲染 9 个魂环卡片，但数量却是 97。
  - 当前剧情却回到了：`【武魂城旧街 · 故乡记忆】`、`家的灯火`，继续出现早年经历的 A/B/C 选择。
  - 日记中还出现了大量“获得第40魂环”到“获得第97魂环”的记录。
- **玩家合理预期：** 完成主线的 Lv.100 存档应进入结局或结局后的状态；魂环数量最多应该是 9/9，当前事件也应该属于后期或结局阶段。
- **为什么影响体验：** 这是最直接的数据可信度崩溃。玩家无法判断魂环、主线、结局和存档是否真实有效，也无法确认自己是否已经完成最终 Boss。
- **是否稳定复现：** 在该网页存档管理中读取这个 Lv.100 存档时稳定复现。属于特定存档稳定复现，不代表每个新角色都会出现。
- **定性：** 明确 BUG，存档数据完整性错误，结局流程缺失。
- **建议修复方向：**
  1. 对魂环索引设置硬上限 9，禁止把“魂环数量”与魂环事件编号混用。
  2. 保存时校验 `level、mainline、currentEvent、ringCount、rings.length` 是否一致。
  3. 完成主线后保存明确的 `endingState`，读取时不得重新生成早年随机事件。
  4. 为旧存档增加版本迁移和异常存档提示，不要让损坏状态看起来像正常存档。
- **页面文字证据：** `主线已完成`、`魂环 97/9`、`家的灯火`。

### P1-02：存档管理混入大量无关历史角色，读取对象不易确认

- **严重程度：** P1
- **玩家实际操作路径：** 游戏内设置 → 存档管理 → 打开。
- **实际看到的结果：**
  - 一次打开可见几十条服务端角色记录，实测有 74 个“读取”按钮，数量还会随环境继续增加。
  - 记录来自不同角色名、不同武魂、不同等级。
  - 每行只有通用的 `读取`、`删除`，缺少清晰的当前用户范围、筛选、排序和确认信息。
  - 读取后确实会切换到另一个等级、武魂、剧情完全不同的角色。
- **玩家合理预期：** 普通玩家应该只看到自己的存档，或者至少看到清晰分组、角色摘要、最后地点、最后剧情和明确的读取确认。
- **为什么影响体验：** 很容易误读其他角色，尤其是多个相同等级或相同角色名的存档。读档之后玩家会认为自己的进度被替换或丢失。
- **是否稳定复现：** 当前部署中稳定看到大量历史存档；具体数量可能随部署数据变化。
- **定性：** 数据边界与 UX 设计问题，伴随潜在存档误操作风险。
- **建议修复方向：**
  - 默认只显示当前玩家的本地/云端存档。
  - 服务端存档增加明确的角色 ID、创建时间、最后地点、主线、魂环数量摘要。
  - 增加搜索、分页、筛选和“读取前确认”。
  - 删除操作必须显示完整角色摘要，而不是只有通用“删除”。

### P1-03：挑战塔进入战斗后，挑战塔弹窗仍然覆盖在战斗界面上

- **严重程度：** P1
- **玩家实际操作路径：** 读取 Lv.50 存档 → 挑战塔 → 点击第 1 层“试炼之门”。
- **实际看到的结果：**
  - 战斗界面已经出现：`第 1 回合`、敌人 HP、普通攻击、魂技、防御、道具、逃跑。
  - 同时挑战塔弹窗仍然存在，页面底部同时出现 `🏰 挑战塔` 的 20 层列表。
  - 如果不先关闭挑战塔弹窗，战斗区域会被覆盖，核心按钮不容易操作。
  - 某次刚打开挑战塔时，第 1 层卡片还出现了点击状态不稳定的情况；之后用实体鼠标点击才进入战斗。
- **玩家合理预期：** 点击“第 1 层”后应关闭塔层选择窗口，进入干净的战斗界面，或者先显示一个明确的“开始挑战”按钮。
- **为什么影响体验：** 玩家会以为战斗没有正常进入，或者认为战斗按钮失效。塔层选择、战斗、关闭按钮的层级关系不清晰。
- **是否稳定复现：** “战斗界面与挑战塔弹窗同时存在”稳定复现；塔层首次点击是否需要重复点击存在状态依赖。
- **定性：** 明确 BUG，弹窗生命周期和交互层级错误。
- **建议修复方向：**
  - 点击塔层后立即关闭塔层选择弹窗。
  - 进入战斗前清理上一个 modal 状态。
  - 将每个塔层做成真正的按钮，并明确显示 `开始挑战`。
  - 战斗期间禁止背景塔层列表继续接收输入。

### P1-04：新的旅程没有完全清理旧角色的全局通知和人物状态

- **严重程度：** P1
- **玩家实际操作路径：** 读取已有角色 → 返回主页 → 新的旅程 → 填名 → 选择出身 → 确认武魂。
- **实际看到的结果：**
  - 新角色顶部已经出现旧的成就提示：`圣者之心 / 在剧情中3次选择仁慈之路`。
  - 新角色仍然出现：`✦ 结识了「唐三」！人物图鉴已更新`，但此时剧情还没有实际见到唐三。
  - 新角色本身显示 Lv.1、魂环 0/9、金币100，但通知内容像是继承了旧角色。
  - 在一次操作中，新的创建页面还保留了旧角色背包弹窗：`回魂丹 ×2`、`聚魂丹 ×1`。
- **玩家合理预期：** “新的旅程”应建立干净的角色、通知队列、人物解锁状态和弹窗状态。
- **为什么影响体验：** 玩家无法判断成就是自己的还是旧角色的，也不知道唐三是否真的被自己结识。
- **是否稳定复现：** 新角色确认后出现历史成就/人物通知可以复现；背包弹窗残留与新建时旧弹窗是否打开有关。
- **定性：** 明确 BUG，跨角色状态污染。
- **建议修复方向：**
  - 新建角色时清空 toast、成就解锁通知、人物解锁提示和 modal 状态。
  - 成就、NPC 图鉴、背包必须明确区分“全局账号数据”和“角色数据”。
  - 新旅程开始前显示明确的“已开始新角色”状态，而不是继续显示“欢迎回来”。

### P1-05：Lv.4 之后主线只显示目标名，没有告诉玩家如何进入目标

- **严重程度：** P1
- **玩家实际操作路径：** 正常新角色 → 完成早年经历 → 报到分班 → 第一堂课 → 继续推进随机事件。
- **实际看到的结果：**
  - 顶部显示：`下一主线：Lv.5「第一次猎杀」`
  - 同时显示：`魂环 0/9 · 下一魂环 Lv.10`
  - 到 Lv.4 后，点击 `▶继续前行` 仍然进入宿舍、食堂、代课老师、蚊子袭击等随机事件。
  - 没有明显的“去狩猎”“进入星斗大森林”“开始第一次猎杀”入口。
  - 地图也没有明确标出第一次猎杀目标。
- **玩家合理预期：** 当主线显示 Lv.5「第一次猎杀」时，应出现任务目标、推荐地点、进入条件和行动按钮。
- **为什么影响体验：** 玩家不知道应该继续刷随机事件、旅行、修炼，还是等待等级提升；魂环系统的核心循环无法自然启动。
- **是否稳定复现：** 在本次正常首通路径中稳定复现，实际只推进到 Lv.4。
- **定性：** 逻辑不通、主线引导缺失、内容闭环缺失。
- **建议修复方向：**
  - 将“下一主线”改成可点击任务卡。
  - 显示：推荐等级、目标地点、预计奖励、是否需要魂环。
  - 到 Lv.5 后自动解锁或明确开启第一次猎杀，而不是继续完全依赖随机事件。
  - 把主线事件与随机事件分栏显示。

### P1-06：第一堂课被每日签到弹窗遮挡，签到计数还自相矛盾

- **严重程度：** P1
- **玩家实际操作路径：** 正常首通 → 入学资格 → 史莱克学院报到与分班 → 第一堂课前后。
- **实际看到的结果：**
  - 第一堂课选择同时出现每日签到弹窗。
  - 弹窗文字为：`连续签到 1 天 · 累计 0 天`
  - 显示第 1 天奖励：`+100 金币`，按钮：`立即签到`
  - 弹窗覆盖了第一堂课的正文和选项区域。
  - 选择分班后，签到弹窗仍然留在页面上。
- **玩家合理预期：** 重要剧情选择应优先于签到弹窗；签到应在玩家主动点击“签到”时出现，或者至少可以不遮挡剧情。连续天数和累计天数也应有清晰定义。
- **为什么影响体验：** 玩家会先处理系统弹窗，而不是沉浸在第一堂课；`1天`和`累计0天`会让玩家怀疑签到是否已经领取。
- **是否稳定复现：** 首次进入学院、当日未签到时稳定出现。
- **定性：** 明确 BUG 加设计问题。
- **建议修复方向：**
  - 首次签到只显示角标或非阻塞提示。
  - 重要剧情期间禁止自动弹出签到 modal。
  - 将 `连续签到`、`累计签到`、`今日是否已领取`分开显示。
  - 领取后立即反馈金币/经验变化。

### P1-07：响应式布局没有保证核心选项和导航可见

- **严重程度：** P1
- **玩家实际操作路径：** 使用浏览器设备模拟检查 390×844、844×390、768×1024、1366×768、1920×1080。
- **实际看到的结果：**
  - **390×844：**
    - 顶部功能菜单部分坐标已经跑到屏幕左侧外部，例如菜单区域出现 `x=-117`、`x=-46`。
    - 三个剧情选项位于 `y=1269` 到 `y=1464`，玩家必须滚动很久才能点击。
  - **844×390 横屏：**
    - 选项底部到 `y=1165`，远超 390 高度。
    - 页面虽然没有明显横向溢出，但核心操作不可见。
  - **768×1024：**
    - 选项位于 `y=1414` 到 `y=1609`。
  - **1366×768：**
    - 第三个选项底部到 `y=843`，超出首屏。
  - **1920×1080：** 相对正常，三项选项可以完整看到。
- **玩家合理预期：** 选项、继续按钮和主导航应该在当前设备上可发现；移动端可以滚动，但不应把核心操作和菜单推到屏幕外。
- **为什么影响体验：** 移动玩家会以为页面没有选项，或者只能不断滚动；横屏时可用高度很低，游戏几乎变成“状态栏 + 长页面”。
- **是否稳定复现：** 五种尺寸的布局问题稳定复现。横向 `scrollWidth` 没有明显超出，但垂直内容和负坐标菜单问题稳定存在。
- **定性：** 响应式 BUG 和布局设计问题。
- **建议修复方向：**
  - 移动端改为底部固定或可折叠导航抽屉。
  - 状态栏、魂环列表和剧情区采用独立滚动区域。
  - 首屏始终保留当前事件标题和至少一个可点击选项。
  - 1366×768 以下自动降低图片高度、减少魂环列表占用。

### P1-08：魂环详情、魂技按钮和战斗技能名称不一致

- **严重程度：** P1
- **玩家实际操作路径：** 读取已有 Lv.50 存档 → 点击第 1 魂环 → 进入挑战塔战斗。
- **实际看到的结果：**
  - 魂环卡片显示：`流光斩 / 独眼狼 / 百年魂环`
  - 魂环详情仍显示：`流光斩`，并写着：`发动火焰攻击`
  - 正式战斗按钮却显示：`🔥 烈焰斩 5魂力`
  - 玩家角色战斗属性显示为：`💧水`
  - 使用战斗技能后日志写：`浏览器魂师释放「烈焰斩」，造成28点伤害`
- **玩家合理预期：** 玩家应明确知道自己获得的魂技叫什么、属于哪个魂环、是什么元素，以及战斗按钮对应哪一个魂技。
- **为什么影响体验：** 玩家无法判断“烈焰斩”是基础技能、魂环技能还是错误名称，魂环描述的火焰攻击与水元素也缺少解释。
- **是否稳定复现：** 在该存档的魂环详情与挑战塔战斗中稳定看到名称不一致。
- **定性：** 明确内容/逻辑 BUG，至少也是严重的信息架构问题。
- **建议修复方向：**
  - 统一魂环卡、魂技详情、战斗按钮和战斗日志使用的技能 ID 与显示名。
  - 如果“烈焰斩”是基础技能，标注为“基础魂技”，不要与魂环技能混在一起。
  - 明确技能元素、魂环元素、武魂元素的关系。

### P1-09：人物解锁提示早于实际剧情，并且在多个事件页面重复

- **严重程度：** P1
- **玩家实际操作路径：** 新角色确认武魂 → 进入序章和早年经历 → 连续点击家庭、重要人物、武魂感应、登记等事件。
- **实际看到的结果：**
  - 在尚未实际见到唐三的场景中已经出现：`✦ 结识了「唐三」！人物图鉴已更新`
  - 该提示在多个连续事件页面都能看到。
  - 正常早期人物图鉴一度只显示极少数已结识人物，但通知却已经指向唐三。
- **玩家合理预期：** NPC 应在真实剧情相遇或互动后解锁，通知只出现一次。
- **为什么影响体验：** NPC 图鉴不再代表玩家真正经历过的剧情，人物关系系统也失去叙事意义。
- **是否稳定复现：** 在正常新角色的早期事件序列中稳定观察到提前的唐三通知和重复提示。
- **定性：** 明确 BUG，事件触发条件错误。
- **建议修复方向：**
  - 将 NPC 解锁绑定到具体事件完成结果。
  - 每个 `npcId` 增加已通知标记。

   - 设置中的导出、导入文件恢复也未验证。

10. **响应式结果来自浏览器设备模拟**
    - 已检查 390×844、844×390、768×1024、1366×768、1920×1080。
    - 未使用实体手机或平板验证触摸滚动、浏览器地址栏占用和真实键盘行为。

## 最优先的十个问题

1. **P0-01：完成存档出现 `主线已完成`、`魂环97/9`，读取后却回到早年剧情。**
2. **P1-02：存档管理混入大量无关历史角色，读取对象不清晰。**
3. **P1-03：挑战塔进入战斗后，挑战塔弹窗仍覆盖战斗操作。**
4. **P1-04：新的旅程继承旧成就提示、NPC 通知和弹窗状态。**
5. **P1-05：Lv.5「第一次猎杀」只有文字提示，没有明确行动入口。**
6. **P1-07：移动端顶部导航和剧情选项被推到屏幕外。**
7. **P1-06：第一堂课被签到弹窗遮挡，签到计数显示矛盾。**
8. **P1-08：魂环技能名称、魂技详情和战斗技能名称不一致。**

## 最终判断

### 1. 玩家能否知道下一步做什么？

前期单个事件内可以，因为每个事件都有 A/B/C 或“继续前行”。  
但到了 Lv.4 后，玩家只看到 `下一主线：Lv.5「第一次猎杀」`，却不知道应去哪里、如何开始、是否要修炼或旅行。整体答案是：**前期部分可以，中后期不能稳定知道。**

### 2. 玩家是否相信数值和奖励？

目前不能。  
`魂环97/9`、完成存档回到早年事件、`元素属性metal`、`主导路线power`、魂环技能和战斗技能名称不一致，都会直接破坏数值可信度。即时奖励有不少真的生效，但反馈不够清楚。

### 3. 玩家是否能感知自己的选择带来了长期变化？

玩家能感知部分即时变化，例如攻击、防御、经验、命运值变化，也能看到某些成就解锁。  
但是 NPC 通知提前出现、关系长期反馈弱、地图和事件地点不一致、存档之间状态污染，使玩家无法确信选择是否真正影响了长期剧情。答案是：**短期能，长期不能稳定感知。**

### 4. 地图、NPC、魂环、战斗和主线是否形成闭环？

目前没有形成可靠闭环：

- 地图有地点和旅行界面，但实际旅行后的事件池和世界变化没有被充分证明。
- NPC 会提前解锁或重复通知。
- 魂环系统在正常首通中没有自然启动，只有 `Lv.10` 门槛提示。
- 战斗界面存在，但挑战塔弹窗会覆盖战斗。
- 主线显示了目标，却没有把玩家导向目标。
- 最终 Boss 和结局没有通过自然流程亲自验证。

### 5. 这款游戏现在最需要减少什么、补什么、重做什么？

- **需要减少：**
  - 首屏同时暴露的系统按钮、数据面板和未解锁系统。
  - 没有完成状态的重复随机事件。
  - 全局成就 Toast、重复 NPC 通知和自动弹窗。
  - 存档管理中大量无关历史角色。

- **需要补：**
  - 从 Lv.4 到第一次猎杀、Lv.10 魂环、后续魂环的确定性主线引导。
  - 地图旅行后的金币、时间、地点和事件池反馈。
  - NPC 关系的真实长期剧情反馈。
  - 挑战塔失败、重试、奖励和最终 Boss 的完整闭环。
  - 结局页面和结局条件说明。

- **需要重做：**
  - 存档数据结构和读取校验，尤其是魂环数量、主线状态、当前事件和结局状态。
  - 挑战塔“选层 → 战斗”的交互层级。
  - 魂环、魂技、战斗技能、元素属性的统一命名和数据展示。
  - 移动端导航、状态栏和剧情选项布局。
  - 让主界面优先服务“当前目标和下一步行动”，而不是展示大量内部数据。## 总体结论

正式网页入口可以完成从创建角色、武魂觉醒、序章、早年经历到第一次正式魂兽战斗，战斗的普攻、敌人回合、胜负、经验、金币和成就记录基本可用。  
但首通在“第一次猎杀”之后没有形成清晰的成长闭环：角色只有 Lv.5 左右，主线却直接跳到 Lv.20，魂环仍是 0/9，第一魂环也没有可见入口。  
地图按钮实际打开的是一个几乎空白的页面，地图地点和旅行功能被拆成两个互不完整的系统。  
早期选择会改变防御、攻击、魂力、命运值和日记，但很多选择并没有形成可感知的剧情分支，甚至出现“选择先去当地学院，下一幕却直接抵达史莱克”的因果冲突。  
移动端主要操作被状态栏和九个魂环卡片推到屏幕下方，390×844 和 768×1024 都需要先滚动才能看到剧情选项。  
整体更像是“功能很多但体验未统一的系统集合”，还不能视为完成度稳定的完整游戏。

本次未发现 P0 级的“完全无法启动、全局存档损坏”问题；最高严重度为 P1。

- **玩家实际操作路径：**

  - `主线：Lv.20「魂师大赛·预赛」`

  - 九个魂环卡全部显示“达到对应等级后猎取 / 未获得”

- **定性：**  
  明确的成长逻辑缺失 / 主线内容缺失。
- **建议修复方向：**  
  第一次猎杀结束后增加明确的“第一魂环准备”事件；将下一主线改为 Lv.10，并显示可到达地点、推荐年份、失败后重试方式。若确实允许 Lv.5 完成教学战，应在结果中明确说明“这不是魂环猎杀，真正猎环需要 Lv.10”。
- **具体页面文字：**  
  `主线：Lv.20「魂师大赛·预赛」` 与 `魂环 0/9 · 下一魂环 Lv.10` 同时出现。

  只在首次结识时通知一次；之后如果关系提升，应显示“关系+1”或新的互动内容。

  玩家会误以为每个事件都重新认识同一个 NPC，通知也会挤占正文和选项的注意力。
- **是否稳定复现：**  
  在完成第一堂课后的同一存档中稳定出现。
- **定性：**  
  重复事件/通知 BUG。
- **建议修复方向：**  
  区分 `npcDiscovered`、`relationshipChanged` 和 `npcInteraction` 状态；已结识人物禁止重复显示发现通知。

### P2-10：经验丹的实际副作用与商店说明不一致

- **建议修复方向：**

## 最终判断

### 1. 玩家能否知道下一步做什么？

开场到第一次猎杀之前，大部分时候可以：序章、学院报到和 Lv.5 主线提示都比较明确。  
第一次猎杀完成后就明显变差，主线跳到 Lv.20，魂环又要求 Lv.10，且没有明确的下一步入口。整体答案是：**前半段基本能，第一次猎杀后不能稳定知道。**

### 2. 玩家是否相信数值和奖励？

战斗伤害、经验、金币、等级和部分剧情属性变化基本可信。  
但铁剑只隐式影响攻击、经验丹额外恢复生命与魂力、`生命恢复+0`、签到初始计数等问题会削弱信任。整体答案是：**部分相信，但奖励说明和实际结果还不一致。**

### 3. 玩家是否能感知自己的选择带来了长期变化？

玩家可以感知即时属性、命运值、日记和成就变化，例如攻击、防御、魂力上限和仁慈/叛逆路线。  
但早期入学、分班和修炼选择大多仍汇入同一地点、同一第一堂课和同一随机事件链，长期世界变化很弱。整体答案是：**能感知短期数值变化，难以感知可靠的长期剧情后果。**

### 4. 地图、NPC、魂环、战斗和主线是否形成闭环？

战斗和旅行分别有一定可玩性；NPC图鉴也能通过剧情结识。  
但是地图页面为空白，NPC关系没有明显互动闭环，第一次猎杀后魂环入口没有接上主线，导致主线、战斗和魂环没有形成完整循环。整体答案是：**没有形成闭环。**

### 5. 这款游戏现在最需要减少什么、补什么、重做什么？

- **减少：** 首屏同时展示的九个魂环卡、过早出现的大量后期系统、重复 Toast、原始数据字段和无效按钮。
- **补上：** 第一次猎杀后的 Lv.10 与第一魂环流程、地图地点与旅行闭环、选择分支的后续剧情、NPC关系互动、后期系统的自然解锁路径。
- **重做：** 移动端布局、主线目标系统、地图容器、奖励反馈层和通知管理。当前最重要的不是继续增加功能数量，而是先让“选择—结果—成长—旅行—魂环—主线”形成一条玩家能理解并相信的闭环。<thinking>**Planning final report based on tested evidence****Assessing P0/P1/P2/P3 severity****Compiling route-by-route findings****Ensuring report meets required structure****Reviewing content and evidence****Avoiding unsupported claims****Clarifying verified versus unverified****Preparing concise but detailed Chinese report**## 总体结论

当前游戏可以完成一部分首通流程：创建角色、选择出身、随机觉醒武魂、跳过或手动推进序章、完成早年经历、进入学院、触发剧情选择，并能进入至少一场正式战斗。  
但“保存后刷新丢失全部角色数据”是阻断性 BUG，足以让玩家无法信任存档系统。  
最影响体验的三个问题是：存档读取失败、移动端顶部布局和通知遮挡、随机武魂觉醒与正式剧情/数值体系之间缺乏稳定对应关系。  
游戏中已经有大量背包、商店、任务、技能树、魂骨、挑战塔、NPC、地图等系统，但它们之间没有形成完整闭环。  
目前更像是“功能很多但体验未统一的系统集合”，而不是一款已经完成首通和成长闭环的文字 RPG。

### P0-01：保存后刷新读取出空角色，造成实际进度丢失

- **严重程度**：P0
- **玩家实际操作路径**：
  1. 打开网页。
  2. 点击“新的旅程”。
  3. 输入名字“保存测试”。
  4. 选择“边境小城”。
  5. 完成武魂觉醒并点击“就是它了”。
  6. 点击“跳过序章”。
  7. 展开“系统”菜单，点击“存档”。
  8. 页面提示“✦ 本地与服务器存档成功”。
  9. 浏览器刷新页面。
- **实际看到的结果**：
  - 路由仍为 `#/game`。
  - 角色名字为空。
  - “武魂：”为空。
  - 等级、生命、魂力、金币、命运值全部归零或为空。
  - 页面显示：
    - “等级 1 · 学院篇”
    - “武魂：”
    - “攻击 0”
    - “防御 0”
    - “生命 0”
    - “速度 0”
    - “金币 0”
    - “命运值 0”
  - 正文变成“魂 / 旅途尚待展开”，并没有恢复刷新前的早年经历。
- **玩家合理预期**：
  - 点击“存档成功”后刷新，应恢复角色名字、出身、武魂、属性、剧情位置和背包。
  - 至少应进入“继续冒险”或读档选择界面，而不是显示半空的游戏状态。
- **为什么影响体验**：
  - 这是玩家最基本的进度安全保障。
  - 存档提示与实际结果相反，会直接破坏玩家对游戏数值和投入时间的信任。
  - 继续点击可能会把空数据再次覆盖本地存档。
- **是否稳定复现**：本次实际操作稳定复现。
- **问题类型**：明确 BUG。
- **建议修复方向**：
  - 将保存和读取使用同一套明确的存档 schema。
  - 刷新时先判断存档完整性，若无有效角色应回到标题页，而不是进入空的 `game` 页面。
  - 存档成功提示必须以“写入并读回校验成功”为条件。
  - 读取失败时显示“存档损坏/不存在”，不要显示看似可玩的空角色。
  - 增加浏览器刷新、关闭重开、读档覆盖等真实回归测试。

### P1-02：移动端顶部状态区、成就通知和导航严重挤压正文

- **严重程度**：P1
- **玩家实际操作路径**：
  - 使用 390×844、844×390、768×1024、1366×768、1920×1080 分别打开网页。
  - 完成创建角色并进入首个早年经历事件。
  - 观察顶部通知、菜单、状态和正文。
- **实际看到的结果**：
  - 390×844 竖屏：
    - 顶部“成就解锁”通知占据明显高度。
    - “展开状态栏”又单独占据一整行。
    - 顶部菜单、天气、状态区和剧情正文被层层推下。
    - 首个剧情选项 C 位于页面下部，需要滚动才能看到。
  - 844×390 横屏：
    - 正文高度非常有限。
    - 三个选项实际位置在页面底部之外，测得：
      - A：y=632～689
      - B：y=701～758
      - C：y=770～827
    - 当前视口高度只有 390，玩家必须频繁滚动。
  - 1366×768：
    - 左侧魂环列表第 6～9 个卡片超出可视区域。
    - 右侧剧情第三个选项 C 也超出首屏。
    - 文档实际高度达到 873，核心操作不是首屏可见。
  - 竖屏 390×844 的菜单展开后，顶部菜单项出现负坐标，部分菜单按钮被推到屏幕左侧之外，例如：
    - x=-106.5
    - x=-35.5
    - x=-7.5
- **玩家合理预期**：
  - 当前剧情正文和所有选项应在合理滚动范围内可见。
  - 菜单不能出现在屏幕外。
  - 通知应该自动收起或不遮挡主要操作。
- **为什么影响体验**：
  - 横屏移动端是文字 RPG 很自然的使用场景，但当前横屏几乎变成“看得到正文、点不到选项”。
  - 玩家可能误以为游戏卡死，或者漏掉剧情选项。
  - 顶部通知比剧情和选项更抢注意力。
- **是否稳定复现**：布局问题在对应视口稳定复现。
- **问题类型**：设计问题 + 明确布局 BUG。
- **建议修复方向**：
  - 移动端重新设计信息层级：成就 Toast 改为短时、可关闭、不占文档流的通知。
  - 横屏时使用双栏或底部固定操作区，保证选项始终可点击。
  - 顶部菜单改为抽屉或下拉面板，按视口边界动态定位。
  - 首屏只保留角色关键状态，魂环列表改为折叠或滚动区域。
  - 对所有核心按钮增加“当前视口内可见且可点击”的自动化断言。

### P1-03：存档成功通知、成就通知和 NPC 通知会长期叠加

- **严重程度**：P1
- **玩家实际操作路径**：
  - 完成首次关键剧情选择，触发“成就解锁”。
  - 继续推进到第一堂课。
  - 观察页面顶部和正文下方的通知。
- **实际看到的结果**：
  - 页面顶部持续出现：
    - “🏆 成就解锁”
    - 成就名称和说明
  - 第一堂课结果正文底部出现：
    - “✦ 结识了「玉小刚」！人物图鉴已更新”
  - 继续点击“继续前行”后，这条玉小刚通知仍然出现在后续事件中。
  - 在后续事件中又结识唐三时，页面仍同时显示玉小刚通知，形成旧通知和新剧情并置。
- **玩家合理预期**：
  - 成就、人物结识、地点提示等应是短暂 Toast，或进入日记/图鉴后消失。
  - 旧通知不应在多个后续事件中持续重复显示。
- **为什么影响体验**：
  - 通知与正文没有清晰边界。
  - 玩家无法判断通知是当前事件的新结果，还是历史记录。
  - 在移动端会直接把正文和选项推到首屏之外。
- **是否稳定复现**：第一堂课后的玉小刚通知持续存在，稳定观察到。
- **问题类型**：明确 BUG + 视觉设计问题。
- **建议修复方向**：
  - 通知必须绑定事件 ID，只展示一次。
  - 使用统一 Toast 队列，设置显示时长、最大堆叠数和优先级。
  - 历史成就和人物信息只保存在日记、图鉴和关系页面。
  - 通知不可覆盖剧情容器和选项容器。

### P1-04：开场动画“跳过”不是立即跳过，需要等待淡出

- **严重程度**：P1
- **玩家实际操作路径**：
  1. 刚打开网页。
  2. 看到全屏“斗罗大陆·武魂觉醒”开场动画。
  3. 点击“跳过开场 ›”。
  4. 立即再次观察页面并尝试点击“新的旅程”。

  - 跳过后直接把焦点移到“新的旅程”。

### P1-05：正式游戏显示的武魂属性与觉醒卡片不是同一套数值

- **严重程度**：P1
- **玩家实际操作路径**：
  1. 进入武魂觉醒页面。
  2. 观察觉醒卡片上的武魂属性。
  3. 点击“就是它了！”进入游戏。
  4. 对比左侧状态栏和属性区。
- **实际看到的结果**：
  - 觉醒卡片例如显示：
    - 武魂：火凤
    - 先天魂力 81
    - 攻击 24
    - 防御 12
    - 生命 250
    - 速度 14
  - 进入正式游戏后显示：
    - 等级 1
    - 生命 201 / 201
    - 魂力 176 / 176
    - 其他攻击、防御等也与觉醒卡片不一致。
  - 不同测试中，多次出现卡片的攻击/生命与正式状态栏不同。
- **玩家合理预期**：
  - 确认武魂后，卡片上的初始属性应直接成为正式角色属性，或者明确说明“基础武魂属性 + 出身修正 + 角色初始模板”。
- **为什么影响体验**：
  - 玩家会认为奖励被偷换或确认按钮没有生效。
  - 武魂品质和出身选择的价值无法判断。
  - 后续升级、魂环和战斗数值都变得不可信。
- **是否稳定复现**：数次随机觉醒均观察到差异；具体差异随随机武魂变化。
- **问题类型**：明确 BUG / 逻辑不一致。
- **建议修复方向**：
  - 统一“觉醒预览”和“角色初始化”的属性计算函数。
  - 卡片中明确拆分：武魂基础值、出身修正、最终初始值。
  - 确认后立即展示最终值，避免玩家看到两套结果。

### P1-06：魂力描述、等级门槛和先天魂力语义不可信

- **严重程度**：P1
- **玩家实际操作路径**：
  - 在觉醒卡片观察“先天魂力”。
  - 进入正式游戏观察“魂力”。
  - 推进早年经历并观察等级。
- **实际看到的结果**：
  - 觉醒卡片出现“先天魂力 81”“先天魂力 94”等非常高的数值。
  - 序章正文也会显示：
    - “你的名字是阿明，先天魂力81级。”
    - 低级武魂也可能显示先天魂力 19、28 等。
  - 正式游戏仍从“等级 1”开始，并且左侧显示魂力上限约 100～190。
  - 主线明确写着“下一主线：Lv.5「第一次猎杀」”，魂环写着“下一魂环 Lv.10”，但玩家看到的“先天魂力 81级”并没有带来等级或魂环变化。
- **玩家合理预期**：
  - “先天魂力”应是魂力资质或初始魂力，而不是看起来像角色等级的“81级”。
  - 如果角色先天魂力达到 81，应解释为什么角色仍是 Lv.1、为什么不能直接进入后期内容。
- **为什么影响体验**：
  - 玩家会认为门槛系统失效或数值单位混乱。
  - “魂力”“等级”“先天魂力”三种概念没有清晰边界。
- **是否稳定复现**：多次随机觉醒和序章均复现。
- **问题类型**：逻辑不通 / 数据展示问题。
- **建议修复方向**：
  - 将“先天魂力”改为明确的资质值或魂力天赋，例如“先天魂力：8.1/10”。
  - 明确角色等级、当前魂力、魂力上限和资质的关系。
  - 让高资质真正影响升级、技能或魂环规则，不能只作为文案。

### P1-07：随机觉醒武魂与序章剧情虽能同步，但世界逻辑断裂

- **严重程度**：P1
- **玩家实际操作路径**：
  - 随机觉醒多个武魂，例如：
    - 铜铃
    - 灯笼
    - 火凤
    - 烈焰马
    - 水晶蛇
  - 点击“就是它了”。
  - 手动推进序章。
- **实际看到的结果**：
  - 序章可以把武魂名称替换成当前武魂，文字中会出现：
    - “器形在掌心由虚转实——你的武魂「铜铃」第一次显现在世间。”
    - “兽影自光中昂首而起——你的武魂「火凤」第一次显现在世间。”
  - 但剧情固定写成“圣魂村”“唐三故乡”“父亲铁匠”等内容。
  - 选择“武魂城世家”时正文地点为“武魂城旧街”，选择“边境小城”时为“边境城墙”，这一点能体现出身影响。
  - 但是早年经历中仍然会出现固定的唐三、大师、史莱克和斗罗原作人物路线，玩家自己的出身和原作主线没有进一步分叉。
- **玩家合理预期**：
  - 不同出身至少应影响家庭、地点、早年人物、推荐学院或后续事件池。
  - 选择随机武魂后，剧情应解释为什么该武魂与当前家庭/地域相符，或明确这是异乡觉醒。
- **为什么影响体验**：
  - 玩家会感觉只是把名字替换进固定模板。
  - 出身选择的长期意义不明显。
  - 世界背景从“你的故事”变成“套用原作名场面”。
- **是否稳定复现**：出身地点差异稳定；后续主线收敛也稳定。
- **问题类型**：逻辑不通 / 设计问题。
- **建议修复方向**：
  - 将出身至少延伸到 3～5 个早期事件、NPC 和目标。
  - 为武魂类型提供不同的早期共鸣和第一魂技预告。
  - 如果主线必须汇入学院线，应在剧情中明确解释汇合原因。

### P1-08：早年经历和第一堂课虽然能走通，但选择后长期反馈弱

- **严重程度**：P1
- **玩家实际操作路径**：
  - 跳过序章。
  - 完成：
    - 家庭事件
    - 重要人物事件
    - 武魂初鸣
    - 武魂殿登记
    - 学院推荐
    - 报到分班
    - 第一堂课
  - 在每个事件选择 A/B/C/D。
- **实际看到的结果**：
  - 事件顺序整体可以完成，确实经历了家庭、武魂共鸣、登记、推荐、报到、分班、第一堂课。
  - 选择后通常只出现一次即时文本和一次即时数值，例如：
    - “攻击+5（武魂共鸣） 命运值+1 经验+39”
    - “生命-10”
    - “魂力上限+6”
  - 继续推进后，主线仍大体进入固定的学院事件和随机事件池。
  - 第一堂课结识玉小刚后，通知在后续事件仍然持续出现。
  - 第一次关键选择会触发“命运之手”，但长期命运路线的差异不容易感知。
- **玩家合理预期**：
  - 选择应至少影响后续事件文本、NPC关系、属性发展方向、可用选项或地点。
  - 玩家应该能知道“我因为之前的选择，所以现在出现了这个结果”。
- **为什么影响体验**：
  - 选择像一次性奖励按钮，而不是角色成长决策。
  - 命运值和路线标签存在，但玩家看不到清晰因果。
- **是否稳定复现**：固定序列和即时结果稳定；长期差异在首通可到达范围内不明显。
- **问题类型**：设计问题 / 内容缺失。
- **建议修复方向**：
  - 给选择写入可读的标签，例如“家庭责任”“攻击路线”“学院推荐”。
  - 后续事件明确引用这些标签。

### P1-09：剧情奖励语义与实际数值不一致，出现“恢复 +0”

    - 当前生命恢复
    - 最大生命增加
    - 受到伤害
    - 生命上限变化

### P2-20：默认背包、商店和事件奖励的资源来源不清晰

- **严重程度**：P2
- **玩家实际操作路径**：
  - 首次跳过序章后打开“背包”和“商店”。
  - 查看金币和初始道具。
- **实际看到的结果**：
  - 初始金币通常为 100。
  - 背包已经有：
    - 回魂丹 ×2
    - 聚魂丹 ×1
  - 商店显示：
    - 回魂丹 30 金
    - 聚魂丹 40 金
    - 解毒丹 50 金
  - 但序章和出身选择没有明确解释这些道具什么时候获得。
- **玩家合理预期**：
  - 初始道具应有来源提示，或者在序章/创建结算中说明。
- **为什么影响体验**：
  - 玩家无法判断是出身奖励、系统赠送还是残留存档。
  - 后续奖励是否重复、是否正确扣除也难以核验。
- **是否稳定复现**：新建角色后可观察到。
- **问题类型**：逻辑说明不足。
- **建议修复方向**：
  - 创建完成结算页显示初始资源清单。
  - 背包记录来源，例如“系统赠送”“出身奖励”“剧情获得”。
  - 商店购买后明确显示金币变化和库存变化。

## 最优先的十个问题

1. **P0：保存成功后刷新读取为空角色，造成全部进度丢失。**
2. **P1：移动端横屏核心选项位于视口底部之外，玩家无法及时点击。**
3. **P1：成就、NPC、存档通知长期堆叠并遮挡剧情和选项。**
4. **P1：觉醒卡片属性与正式角色状态不一致。**
5. **P1：先天魂力、角色等级、魂力上限和魂环门槛的单位/语义混乱。**
6. **P1：Lv.5 主线要求前往星斗大森林，但地图和旅行没有清晰可达入口。**
7. **P1：地图是静态展示，地点不可点击，主线与地图没有闭环。**
8. **P1：剧情奖励显示“生命恢复+0”等无法判断是否生效的结果。**
9. **P1：魂技、NPC、技能树、魂骨和挑战塔入口存在，但早期缺少实际可玩闭环。**
10. **P2：移动端和觉醒页面出现菜单越界、图片/图标异常字符串、英文 rarity 标签等明显视觉与数据展示问题。**

## 最终判断

### 1. 玩家能否知道下一步做什么？

只能部分知道。

- 首次创建角色、觉醒武魂、跳过序章、点击剧情选项，这些步骤基本明确。
- 到达 Lv.5 后，系统告诉玩家“前往星斗大森林外围”，但没有给出可靠的地图热点、旅行入口或主线按钮。
- 帮助页面提到“探索”按钮，但当前实际界面并没有明显的探索按钮。
- 因此首通前半段尚可，进入成长主线后明显迷失。

### 2. 玩家是否相信数值和奖励？

目前不能。

主要原因：

- 觉醒卡片属性与正式角色属性不一致。
- 先天魂力出现 19、28、81、94 等看似等级的数值，但角色仍从 Lv.1 开始。
- “生命恢复+0”没有说明是满血还是奖励失效。
- 战斗经验和跨级结果缺少清晰的前后对照。
- 存档提示成功但刷新后角色为空。

其中存档问题是最严重的信任破坏点。

### 3. 玩家是否能感知自己的选择带来了长期变化？

目前很弱。

- 早期选择确实会改变即时属性、命运值、经验和结果文案。
- 不同出身也会改变开场地点和部分初始状态。
- 但后续剧情很快汇入固定的史莱克学院路线。
- 玩家难以看到选择如何影响人物关系、地图、事件池、技能路线或最终结局。
- “命运之路”“英雄之路”“宗门之路”等标签出现了，但其长期效果不够可感知。

### 4. 地图、NPC、魂环、战斗和主线是否形成闭环？

目前没有形成。

- **地图**：视觉展示为主，地点不可点击。
- **NPC**：可以触发结识通知，但关系页面和后续互动反馈不足。
- **魂环**：早期只能看到九个空槽，实际获取路径尚未自然到达。
- **战斗**：可以进入并完成普通攻击，但和魂技、魂环、主线之间的连接不完整。
- **主线**：到 Lv.5 提出星斗大森林目标，却没有稳定的前往入口。
- **成长系统**：技能树、魂骨、锻造、挑战塔等页面很多，但早期资源和玩法没有自然来源。

### 5. 这款游戏现在最需要减少什么、补什么、重做什么？

- **减少**：
  - 顶部常驻通知。
  - 首屏同时展示的魂环卡片和未解锁系统。
  - 直接展示后期数据的图鉴列表。
  - 与实际操作不一致的帮助文案。
  - 只是显示按钮但没有可达后续的系统入口。

- **补上**：
  - 可靠的保存、读取、刷新恢复机制。
  - Lv.5 主线到星斗大森林的明确路径。
  - 魂环获取、失败、重试、魂技解锁的完整首通流程。
  - 选择对人物关系、事件池和后续结局的长期反馈。
  - 通知队列、移动端布局和横屏操作区。
  - 统一的属性、奖励和经验结算格式。

- **重做**：
  - 地图与旅行系统，不能只做成图片展示。
  - 觉醒卡片到角色初始化的数值管线。
  - 早年经历到学院主线的内容结构。
  - NPC、魂环、战斗、技能树和主线之间的闭环。
  - 移动端顶部导航和通知布局。

当前最合理的产品判断是：**可玩的文字 RPG 原型，已经具备不少系统页面和部分剧情，但尚未达到可以让玩家放心投入时间的完整游戏状态。**
