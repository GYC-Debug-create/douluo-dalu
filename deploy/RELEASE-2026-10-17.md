# 2026-10-17 内测上线（不开放注册）

部署包：`deploy/douluo-release-20261017.tgz`（已含构建好的 `frontend/dist`，不含任何存档/账号/密钥）。

## 本次改动

- **关闭注册**：`/api/auth/register` 默认返回 403，标题页去掉「注册」按钮；账号只能由管理员创建。临时开放需在 compose 里设 `ALLOW_REGISTER: "1"`。
- **防猜密码**：同一账号连续输错 5 次锁定 15 分钟；登录接口按 IP 每分钟 10 次；账号不存在时响应耗时与存在时一致。
- **改密/重置即踢下线**：改密码或管理员重置后，该账号所有旧登录立即失效（当前设备自动换新 Token）；删除账号后其登录立即失效。新密码至少 6 位。
- **账号热加载**：服务运行中用 `account-admin.js` 建号/改密立即生效，无需重启（修复了此前服务端会把内存旧账号表写回、覆盖管理员新建账号的问题）。
- **越权修复**：无主旧档、损坏档不再能被任意登录用户删除；看历史版本必须是存档本人。每账号最多 30 个存档。
- **Bug**：输错「原密码」不再被直接登出；Dockerfile 里旧轨文件路径已失效会导致镜像构建失败，已修正。
- `/api/health` 对外只返回 `status`，内存/存档数等细节仅本机可见。

## 服务器操作

```bash
# 0. 备份存档卷（必做）
docker exec douluo-game-app tar -C /app/data -czf /tmp/bak.tgz .
docker cp douluo-game-app:/tmp/bak.tgz /root/douluo-data-bak-$(date +%Y%m%d-%H%M).tgz

# 1. 上传并解压（本机执行 scp，服务器执行 tar）
scp deploy/douluo-release-20261017.tgz 用户@49.233.157.164:/tmp/
cd /opt/apps/douluo && sudo tar -xzf /tmp/douluo-release-20261017.tgz -C /opt/apps/douluo

# 2. 重建并启动
sudo docker compose -f docker-compose.production.yml build
sudo docker compose -f docker-compose.production.yml up -d
curl -fsS http://127.0.0.1:3001/api/health          # {"status":"ok",...}

# 3. 账号管理（运行中直接改，立即生效）
docker exec douluo-game-app node scripts/account-admin.js list
docker exec douluo-game-app node scripts/account-admin.js create 用户名 初始密码     # 密码至少 6 位
docker exec douluo-game-app node scripts/account-admin.js set-password 用户名 新密码
docker exec douluo-game-app node scripts/account-admin.js remove 用户名

# 4. 验证注册已关闭（应返回 403）
curl -s -o /dev/null -w '%{http_code}\n' -X POST -H 'content-type: application/json' \
  -d '{"username":"abc","password":"abcdef"}' http://127.0.0.1:3001/api/auth/register
```

## 仍需注意

- **目前是 HTTP 明文**，密码和登录凭证在网络上可被截获。域名 A 记录生效后务必执行 `sudo certbot --nginx -d gyc1313.tech` 上 HTTPS（见 `deploy/README.md`）。
- 之前文档里的初始密码 `123456` 太弱，建议上线后用 `set-password` 给每个账号换成不易猜的密码。
